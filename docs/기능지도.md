# 기능 지도

사용자 관점의 기능 목록이에요. 사용자가 "왼쪽 사이드바 검색"처럼 부르는 이름과 코드·시나리오·확인 스크립트를 한 줄로 잇습니다.
- 사람과 에이전트가 같은 이름으로 말하게 하는 공통 어휘예요. 사용자가 화면을 어떻게 부르든 여기서 ID 를 찾아요.
- `qa-check`·`scenario-review` 는 확인하기 전에 이 표에서 확인 스크립트를 찾아 돌리고, 손으로 확인한 흐름은 `scripts/verify/` 에 스크립트로 남긴 뒤 이 표에 적어요.
- `scripts/harness/check-map.sh` 가 ID 중복, 코드·확인 스크립트 경로, 시나리오 ID(`docs/시나리오.md`)를 검사해요(CI 에서도 돌아요).

칸 약속
- 경로는 백틱으로 감싸고 `/` 나 `.` 을 넣어요. 여러 개면 쉼표로 나눠요.
- 경로는 하나씩 백틱으로 감싸요(`src/a.ts`, `src/b.ts`). 백틱 밖 글은 검사하지 않아요.
- 확인 스크립트가 아직 없으면 `손`(손으로 확인)이라고만 적어요. 비워 두거나 다른 말을 쓰면 check-map 이 실패해요.
- 시나리오는 `SC-01` 꼴로 적고, 없으면 `-`.

예:
```
| F1 | 왼쪽 사이드바 검색 | 홈 → 왼쪽 사이드바 돋보기 | `src/features/search/` | SC-01 | `scripts/verify/F1-search.sh` |
```

| ID | 사용자가 부르는 이름 | 어디서 (진입 경로) | 코드 | 시나리오 | 확인 스크립트 |
|---|---|---|---|---|---|
