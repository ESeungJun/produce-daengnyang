# 프로듀스 댕냥 기획서

> "국민 집사님, 우리 애 데뷔시켜 주세요."
> 강아지·고양이 사진을 올리고 투표로 이번 주 **센터**와 이달의 **데뷔**를 뽑는 웹 + 웹앱(PWA) 서비스.

- 작성: 2026-11-17
- 상태: 확정 (2026-11-17 사용자 확인)

## 1. 목적과 배경

**해결하려는 문제**
- 집사는 우리 애를 자랑하고 싶고, 반려동물 SNS 계정의 팔로워를 늘리고 싶다. 그런데 인스타·틱톡 안에서는 수많은 게시물에 묻힌다.
- 귀여운 동물을 보는 사람은 "누가 제일 귀엽나"를 정하는 재미가 있지만, 한국에는 상시로 돌아가는 강아지·고양이 투표 사이트가 없다(조사 범위 안에서는 신문사·정부 기관이 1년에 한 번 여는 공모전뿐).

**이루려는 상태**
- 매주 강아지·고양이 게시판에서 투표로 1위(센터)가 나오고, 그 센터가 다음 주 동안 사이트 배너를 차지한다.
- 매달 결선에서 1위(데뷔)가 나오면 다음 달 내내 사이트 전체가 그 아이로 도배된다.
- 배너를 누르면 주인의 인스타·틱톡·유튜브로 넘어가서, 1위가 실제로 팔로워를 얻어 가는 구조.

**컨셉**: 아이돌 오디션 방송 패러디. 화면 문구를 모두 이 말투로 맞춘다.

| 서비스 기능 | 화면에서 부르는 이름 |
|---|---|
| 사진 올리기(참여 신청) | 연습생 등록 |
| 투표 | 픽 (하루 픽 3장) |
| 주간 1위 | 이번 주 센터 |
| 주간 1·2위 | 결선 진출 (데뷔조 후보) |
| 월간 결선 | 데뷔 평가 |
| 월간 1위 | 이달의 데뷔 |
| 지난 1위 모음 | 명예의 전당 |
| 투표하는 사람 | 국민 집사님 |

## 2. 주 타깃

**주 타깃 A: 자랑하고 싶은 SNS 집사**
- 20~30대, 반려동물 인스타·틱톡 계정을 운영하거나 사진을 자주 찍는다.
- 동기: 우리 애가 1등 하는 걸 보고 싶다 + 내 계정 팔로워를 늘리고 싶다.
- 행동: 사진을 올리고, 자기 SNS·단톡방에 "투표해 줘" 링크를 뿌린다. → 이 공유가 서비스의 주된 유입 경로가 된다.

**주 타깃 B: 귀여운 거 보러 오는 구경꾼**
- 반려동물이 없거나 있어도 올리지는 않는 사람. 친구가 보낸 링크로 처음 들어온다.
- 동기: 귀여운 사진 구경, 내가 픽한 애가 이기는 재미.
- 행동: 하루 3픽을 쓰고, 마음에 드는 애의 SNS를 팔로우한다.

## 3. 성공지표

| 구분 | 지표 | 측정 방법 | 목표(출시 후 첫 3개월) |
|---|---|---|---|
| 핵심 | 주간 픽 참여자 수 | 한 주에 1표 이상 던진 고유 계정 수 (votes 테이블) | 3개월째 주당 500명 |
| 보조 | 라운드당 연습생 등록 수 | 게시판별 라운드 등록 글 수 | 게시판마다 라운드당 30장 이상 |
| 보조 | 배너 SNS 이동률 | 배너 노출 대비 SNS 링크 클릭 (이벤트 로그) | 2% 이상 |
| 보조 | 다음 주 재방문율 | 이번 주 픽한 사람 중 다음 주에도 픽한 비율 | 30% 이상 |

목표 수치는 출시 첫 달 실측을 보고 다시 맞춘다.

## 4. 기능 목록

### 필수 (1차 출시)
- **구글 로그인**. 로그인 없이도 구경은 전부 가능하고, **비로그인 픽은 하루 1번**까지 된다.
  - 두 번째 픽을 누르거나 연습생 등록을 누르면 그 자리에서 로그인 안내(아래에서 올라오는 시트, "구글로 계속하기"). 로그인이 끝나면 하려던 픽·등록을 이어서 한다.
  - 비로그인 픽은 기기(쿠키)와 접속 정보로 하루 1번을 센다. 로그인하면 그날 한 비로그인 픽이 계정으로 옮겨져 3픽 중 1장으로 계산된다(같은 글 하루 1픽 규칙도 그대로).
  - 비로그인 픽도 순위에 바로 들어간다. 쿠키를 지워 반복하는 악용은 봇 확인(Cloudflare Turnstile 같은 보이지 않는 확인)과 접속 정보별 하루 한도로 막는다.
- **게시판 두 개**: 강아지, 고양이. 서로 완전히 따로 경쟁한다.
- **연습생 등록**: 사진 1~3장(첫 장이 대표 사진) + 이름(필수) + 짧은 소개글(100자, 선택) + SNS 링크(인스타·틱톡·유튜브, 선택). 글은 사진 중심, 긴 글 없음.
  - **임시 저장**: 쓰던 내용(사진 포함)이 이 기기에 자동으로 남는다. 로그인 시트를 다녀오거나 창을 닫았다 와도 이어서 쓴다. 등록하면 지운다.
  - 한 사람이 **한 라운드에 두 게시판 합쳐 최대 2번** 등록(강아지 2, 고양이 2, 강아지+고양이 모두 가능).
  - 사진 크기 줄이기·EXIF(위치 정보) 지우기는 올리기 전에 브라우저에서 처리(설계서 1-7).
- **내 글 관리**(게시판 기본 기능, 2026-11-18 추가)
  - **수정**: 이름·소개글·SNS 링크는 라운드가 끝나기 전까지 언제든 고칠 수 있다. **사진(추가·삭제·순서)은 픽을 하나도 받기 전까지만** 바꿀 수 있고, 첫 픽을 받으면 잠긴다(표를 모은 뒤 다른 아이 사진으로 바꿔치기 방지).
  - **삭제**: 언제든 지울 수 있다. 지워도 그 라운드 등록 횟수는 돌려주지 않는다(지우고 다시 올려 표를 초기화하는 악용 방지). 받은 픽도 픽한 사람에게 돌려주지 않는다. 결선 진출 글을 지우면 그 라운드 3위가 이어받는다.
  - **내 글 목록**: 내 정보 화면에서 지금까지 올린 글을 라운드별로 본다(순위·표 수·받은 배지). 가림 기간에는 내 글의 표 수도 가린다.
- **이름 검색**: 게시판 위 검색칸에서 지금 라운드의 아이를 이름으로 찾는다(두 글자부터, 일부만 맞아도 됨). 공유 링크 없이 "우리 애 찾아서 픽해 줘"로 온 사람을 위한 길.
- **조회수**: 글마다 본 사람 수. 같은 사람(기기)은 하루 한 번만 센다. 표 수와 같이 가림 기간에는 숨긴다. 참고용이라 정확하지 않아도 된다(감수).
- **픽(투표)**
  - 한 사람이 **게시판마다 하루 3픽**(강아지 3 + 고양이 3). 같은 글에는 **하루 1픽**만(다음 날 다시 가능).
  - 라운드 중 순위는 공개하고, **마감 24시간 전부터는 순위·표 수를 가린다**("최종 순위 발표"까지 긴장감). 결선도 같다.
  - 픽 버튼은 게시판에 따라 모양이 다르다: 강아지 게시판은 강아지 얼굴, 고양이 게시판은 고양이 얼굴. "오늘 남은 픽"도 같은 얼굴 3개로 보여 준다.
- **게시판 보기**: 이번 라운드에 등록된 아이를 **모두** 보여 준다. 정렬은 **인기순**(기본)·**최신순**. 마감 24시간 전 가림 기간에는 인기순이 순위를 드러내므로 인기순 자리에 **섞어 보기**(접속할 때마다 순서가 바뀜)를 둔다.
- **댓글**: 글마다 간단한 댓글(한 줄, 100자까지). 픽을 하지 않아도 달 수 있다. 로그인한 사람만 쓸 수 있고(구경은 누구나), 내 댓글은 지울 수 있다. **댓글마다 신고 버튼**이 있고, 신고·욕설 걸러내기는 사진 신고와 같은 관리자 화면에서 처리. 글 주인에게 "새 댓글" 알림(알림함만, 메일·푸시는 보내지 않음).
  - 하루는 한국 시간 00:00~23:59 기준. 자정에 픽 3장이 다시 채워진다.
  - 내 글에는 픽할 수 없다.
- **일정(매달 반복, 한국 시간)**

  | 기간 | 라운드 | 결과 |
  |---|---|---|
  | 1일~7일 | 주간전 1라운드 | 게시판마다 1·2위 결선 진출, 1위는 8~14일 센터 |
  | 8일~14일 | 주간전 2라운드 | 〃, 1위는 15~21일 센터 |
  | 15일~21일 | 주간전 3라운드 | 〃, 1위는 결선 기간(22일~말일) 센터 |
  | 22일~말일 (7~10일) | 데뷔 평가(결선) | 게시판마다 결선 진출 6마리 중 1위가 다음 달 내내 데뷔 |

  - 달 길이와 상관없이 주간전은 항상 3번, 결선 진출자는 게시판마다 항상 6마리라서 매달 공평하다.
  - 결선 기간에는 새 등록을 받지 않는다(결선 진출자만 경쟁).
  - 동점이면 그 표 수에 먼저 도달한 글이 이긴다.
  - 결선 진출자가 글을 지우거나 탈퇴하면 그 라운드 3위가 이어받는다.
- **1위 도배**
  - 이달의 데뷔(월간 1위): 다음 달 내내 메인 첫 화면 전체 + 모든 페이지 상단 배너.
  - 이번 주 센터(주간 1위): 다음 라운드 동안 메인 둘째 칸 + 해당 게시판 상단.
  - 결선 진출자: 결선 전까지 메인의 "데뷔조 후보" 줄에 계속 노출(첫 주에 뽑힌 아이가 오래 기다리는 동안에도 보이게).
  - 배너를 누르면 주인의 SNS로 이동. SNS가 없으면 그 아이의 글로 이동.
- **보상 나눔**(첫 주 진출자가 결선까지 오래 기다리는 문제)
  - 주간 1위: 발표 즉시 다음 라운드 센터 배너 + 알림·메일 + 센터 배지.
  - 주간 2위: 결선 진출 배지 + 알림·메일.
  - 월간 1위: 다음 달 사이트 전체 도배 + 명예의 전당 + 알림·메일 + 데뷔 배지.
- **알림**: 사이트 알림함 + 메일 + 웹 푸시. 보내는 때: 센터 선정, 결선 진출, 데뷔 확정.
  - 웹 푸시는 아이폰에서는 홈 화면에 웹앱을 설치해야 받을 수 있다(iOS 16.4 이상). 설치 안내를 알림 켜기 화면에 넣는다.
- **명예의 전당**: 지난 센터·데뷔 모음.
- **신고와 관리자 화면**: 동물이 아닌 사진·불쾌한 사진 신고 → 관리자가 숨김. 라운드 결과는 자동 확정, 관리자가 문제 글을 빼고 다시 계산할 수 있다.
- **웹앱(PWA)**: 홈 화면 설치, 앱 아이콘, 오프라인 안내 화면.
- **공유**: 글마다 공유 링크와 미리보기 이미지(카톡·인스타 링크 미리보기). "우리 애 픽해 주세요" 문구 자동 생성.

### 나중
- 사진이 강아지·고양이인지 AI로 자동 확인.
- 다계정 의심 투표 탐지(가입 직후 대량 픽, 같은 기기 여러 계정).
- 센터·데뷔 축하 카드 이미지 만들어 주기(SNS에 올릴 용).
- 앱 스토어 출시(PWA를 감싸는 방식).
- 광고·제휴(8절).

### 범위 밖
- 유료 투표. 해외 대회에서 "돈 내야 이긴다"는 불만이 가장 컸다(6절). 표는 언제나 무료.
- DM, 대댓글, 팔로우 같은 커뮤니티 기능(한 줄 댓글만 둔다).
- 강아지·고양이 외 동물.

## 5. 사용자 흐름

### 정상 흐름
1. **구경꾼**: 친구가 보낸 글 링크로 들어옴 → 그 아이 사진과 "픽" 버튼 → 로그인 없이 바로 픽(하루 1번) → "로그인하면 하루 3픽까지 할 수 있어요" 안내 → 게시판에서 다른 아이에게 픽을 누르면 로그인 시트 → 구글 로그인 → 그 픽이 바로 들어가고 남은 픽 표시.
2. **집사**: 메인의 "연습생 등록" → 구글 로그인 → 강아지/고양이 고르기 → 사진 1~3장·이름·소개글·SNS 링크(쓰는 동안 임시 저장) → 등록 → 공유 링크 받기 → 내 SNS에 공유. 나중에 내 정보 → 내 글에서 고치거나 지운다.
3. **라운드 마감**: 7일 23:59 마감 → 00:00에 결과 확정 → 1·2위 주인에게 알림·메일·푸시 → 메인 배너가 새 센터로 바뀜.
4. **데뷔 평가**: 22일부터 게시판마다 진출자 6마리만 보이는 결선 화면 → 말일 마감 → 다음 날 00:00 데뷔 확정 → 사이트 전체가 새 데뷔로 바뀜.

### 예외 흐름
- 비로그인으로 오늘 픽을 이미 했는데 또 누름 / 비로그인으로 연습생 등록이나 댓글 쓰기를 누름 → 로그인 시트. 닫으면 그대로 구경 계속(쓰던 댓글은 남겨 둠).
- 댓글에 금지어가 있거나 100자를 넘음 → 보내기 전에 안내.
- 픽을 다 썼는데 또 누름 → "오늘 픽을 다 썼어요. 자정에 3장이 다시 생겨요" + 남은 시간.
- 오늘 이미 픽한 글을 또 누름 → 버튼이 "오늘 픽 완료"로 꺼져 있음.
- 라운드에 2번 다 등록했는데 또 등록 → "이번 라운드 등록을 다 썼어요. 다음 라운드는 n일에 열려요".
- 결선 기간에 등록 → "지금은 데뷔 평가 중이에요. 다음 달 1일에 새 라운드가 열려요".
- 사진이 너무 크거나 형식이 다름 → 업로드 전에 화면에서 줄이고, 지원 안 하는 형식은 안내.
- SNS 링크가 인스타·틱톡·유튜브 주소가 아님 → 저장 막고 안내(아무 사이트로나 보내는 링크 악용 방지).
- 1위 글이 신고로 숨겨짐 → 다음 순위가 이어받고 배너도 바뀜.
- 픽을 받은 글의 사진을 바꾸려 함 → 사진 칸이 잠겨 있고 "픽을 받은 뒤에는 사진을 바꿀 수 없어요. 이름·소개·SNS는 고칠 수 있어요" 안내.
- 글 지우기 → 확인 시트("지워도 이번 라운드 등록 횟수는 돌아오지 않아요"). 지운 글 링크로 들어오면 "지워진 글이에요" + 게시판으로 가기.
- 검색 결과 없음 → "이번 라운드에 '…' 연습생이 없어요" + 최신순 보기.
- 다른 기기에서 등록 화면을 열면 임시 저장은 없음(이 기기에만 남음).
- 알림을 껐거나 메일이 실패 → 알림함에는 항상 남는다.
- 마감 직전(23:59:59)에 누른 픽 → 서버가 받은 시각 기준으로 판정.

**좋은 레퍼런스 (가져올 점)**

- America's Favorite Pet: "돈을 많이 쓰지 않으면 이길 수 없다", "항상 우리 애가 이기고 있는 것처럼 느끼게 만든다"는 불만이 많다([PetsWeekly 분석](https://petsweekly.com/?p=7310), [DeleteMe](https://joindeleteme.com/is-it-scam/is-americas-favorite-pet-a-scam/)). → **유료 표 없음**, 순위는 실제 표 그대로 보여 준다.
- 한국 공모전: 1년에 한 번이라 재방문 이유가 없다. → 매주 결과가 나오는 리듬.

## 7. 강점·약점

**강점**
- 한국어로 상시 돌아가는 강아지·고양이 투표 서비스가 (조사 범위 안에서) 없다.
- 표가 무료이고 규칙(하루 3픽, 같은 글 하루 1픽)이 단순해서 공정하다고 느끼기 쉽다.
- 1위에게 "SNS 유입"이라는 실제 보상이 있어서, 집사가 스스로 링크를 퍼뜨린다(유입 비용이 거의 안 든다).
- 오디션 패러디 말투로 공유할 때 재미가 있다.

**약점과 대응**
- **처음에 참가자가 적으면 썰렁하다** → 출시 첫 달은 지인·반려동물 커뮤니티에 홍보, 게시판이 비어 있을 때 "첫 연습생이 되어 보세요" 화면. 라운드 등록이 적어도 그대로 진행(감수).
- **비로그인 픽 반복**(쿠키 지우기·시크릿 창) → 비로그인 픽은 하루 1번 + 접속 정보별 하루 한도 + 보이지 않는 봇 확인. 그래도 일부는 새어 나감(감수). 나중에 비로그인 픽이 순위를 좌우하는 일이 생기면 비로그인 픽의 무게를 낮추는 안을 검토.
- **다계정으로 표 몰아주기** → 1차는 구글 로그인 + 하루 3픽 제한으로 막고, 의심 패턴 탐지는 나중. 완전히 막지는 못함(감수).
- **동물이 아닌 사진·불쾌한 사진** → 신고 + 관리자 숨김. 자동 판별은 나중.
- **'프로듀스' 이름의 상표 문제**: 특정 방송 이름과 비슷해서 상표 분쟁 가능성이 있다 → 출시 전에 상표 검색(KIPRIS)으로 확인하고, 문제가 되면 이름만 바꿀 수 있게 이름을 코드 한 곳에서만 쓴다. 방송 로고·폰트·색은 따라 하지 않는다.
- **아이폰 웹 푸시는 홈 화면 설치가 필요** → 메일과 알림함으로 반드시 전달되게 하고, 푸시는 덤으로 둔다.

## 8. BM·광고

1차 출시는 광고 없이 간다(사용자 결정). 나중에 넣을 자리만 잡아 둔다.

| 자리 | 종류 | 노출 | 경험 손해 | 기대 | 비고 |
|---|---|---|---|---|---|
| 게시판 목록 중간(12장마다 1칸) | 네이티브 배너 | 높음 | 낮음 | 중간 | 픽 버튼 근처는 피한다 |
| 결선(데뷔 평가) 페이지 | 브랜드 협찬("이번 달 데뷔 평가는 OO 사료와 함께") | 월 1회 | 낮음 | 높음 | 참가자가 늘어난 뒤 |
| 명예의 전당·글 상세 하단 | 반려용품 제휴 링크 | 중간 | 낮음 | 낮음~중간 | 제휴 표기 의무 |

넣지 않는 자리: 픽 버튼 주변, 전면 광고, 사진을 가리는 광고, 1위 배너 영역.
