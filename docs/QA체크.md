## #11 후속 개선과 SNS 종류 변경 (2026-11-18)

| # | 항목 | 확인 방법 | 결과 |
|---|---|---|---|
| 1 | 글의 SNS 칸이 인스타·스레드·유튜브, 스레드 칸에 틱톡 주소는 거절 | pgTAP(스레드 저장·틱톡 거절), Vitest `snsHandle` | ✅ |
| 2 | 센터 화보 이름 아래 SNS 칸, 누르면 그 아이 SNS(새 탭) | 휴대폰 라이트·다크 캡처, 링크 주소 확인 | ✅ |
| 3 | 게시판·글 상세 맨 위 "이번 주 센터" 띠, 이름 → 글 상세, 옆 글자 → SNS | 휴대폰·데스크톱 캡처 | ✅ |
| 4 | 가림 기간 손님마다 섞인 순서가 다름(방문자 키 seed), 더 보기도 같은 seed | pgTAP(seed 순서), 코드 | ✅ |
| 5 | 노출·클릭이 기록되고 같은 사람·날은 한 번 | 브라우저에서 메인·게시판·상세를 열고 SNS 클릭 → `sns_events` 행 확인, pgTAP | ✅ |
| 6 | 응답에 CSP·보안 헤더, 사진·픽·더 보기가 CSP 에 막히지 않음 | `curl -I`, 회원 픽·SNS 클릭이 동작 | ✅ |
| 7 | 글자 크기 px 가 모두 토큰, 값은 그대로 | `grep font-size: [0-9]px` 결과 0줄 | ✅ |
| 8 | 회원 판정(getClaims) — 시험 회원이 "강아지 픽 2장 남음" | 시험 회원 쿠키로 픽 | ✅ |
| 9 | 첫 화면 JS 감소 | 운영 빌드 `/`·`/dog` 첫 스크립트 합: gzip 256.9KB → 189.5KB | ✅ |
| 10 | 단위·DB 시험 | Vitest 34개, pgTAP 108개 | ✅ |
| 11 | 라이트 모드 센터 SNS 칸 글자가 보임(리뷰 1회차에서 찾은 문제) | 메인 휴대폰·데스크톱 라이트·다크 캡처 | ✅ |
| 12 | 기록 함수 하루 상한·빈 값 | pgTAP(상한 넘으면 0, 종류 null 이면 0) | ✅ |
