# 프로듀스 댕냥 디자인 시스템 (확정안 V2A)

- 원본 토큰: [`shared/styles/tokens.css`](../../shared/styles/tokens.css). 이 문서와 값이 1:1로 같아요.
- 견본 페이지(Artifact)와 확정 시안 링크: [FIGMA.md](FIGMA.md)의 "디자인 원본 위치"
- 확정 시안 파일: `.work/mockups/시안_확정_V2A.html`(휴대폰 메인 라이트·다크, 강아지 게시판, 글 상세, 데스크톱 메인)
- Figma는 쓰지 않아요. 사용자 Figma 계정이 보기 권한뿐이라 Artifact 견본 페이지로 대신해요(결정기록 2026-11-17).

## 0. 어떻게 정해졌나
v2(귀여운 매거진)를 처음 그렸어요. 그런데 검수를 건너뛰었고, 사용자가 "AI 티가 난다"고 지적했어요. 그래서 앱 화면 규칙으로 v3(무채색 장부)를 다시 그렸어요.

v3를 비교해 본 사용자의 판단은 이랬어요. **매거진 느낌, 배치, UI 부품은 v2가 낫고 색감은 v3가 낫다.** 그래서 v2를 그대로 두고 색 토큰만 바꾼 A안(v3 색감)과 B안(v2 색 다듬기)을 만들었고, 사용자가 **A안을 확정**했어요(결정기록 2026-11-18).

- 사진 위 글자 그림자·그늘, 알약 칩, 점선 같은 v2 부품은 사용자 결정으로 유지해요. design-taste-frontend의 앱 화면 규칙과는 일부러 다르게 가요.
- v2 원본에서 대비가 모자랐던 곳은 A안에서 고쳤어요.

## 1. 컨셉
매달 한 권 나오는 반려동물 잡지예요. 휴대폰 메인은 한 권을 넘기는 순서로 놓여요.

1. 표지: 그달 데뷔한 아이(1280px 이상은 가운데 잡지 표지 한 장 + 양옆 세로 배너, #16·#25)
2. 사이트 소개 + 바로가기(#16 에서 "○월호 목차"를 바꿈)
3. 화보: 이번 주 센터
4. 차트: 라운드 순위
5. 후보 폴라로이드: 데뷔조 후보
6. 모집 공고: 연습생 등록(전체 폭 + 포스터)
7. 사이트 푸터(#16 에서 맨 아래 제호를 바꿈)

잡지 비유는 색·글꼴·폴라로이드 같은 꾸밈에만 남기고, 글로 "○월호"·큰 제호를 말하지는 않아요(#16 사용자 의견: 무슨 화면인지 모르겠다).

틀은 종이·잉크·회색이고, **분홍 하나**가 "누르는 곳"과 강조를 맡아요. 귀여움은 굵은 제호 글꼴, 알약 모양, 발도장 픽 버튼, 기울어진 폴라로이드가 맡아요.

## 3. 글자
- 제호·제목·숫자는 **Black Han Sans**, 본문은 **Gowun Dodum**이에요(Google Fonts).
- 크기: 표지 이름 52, 세로 배너 이름 40~64(`--pd-fs-d-rail`), 게시판 제목 38(글 상세 이름 40), 섹션 제목 32, 순위 숫자 30, 마감 시계·시트 제목 24, 바로가기 제목 22, 윗줄 로고 20, 본문 15, 보조 13, 표 수·날짜 12.

## 4. 모서리·간격·그림자
- 모서리
  - 알약 999: 버튼·탭·칩(입력칸은 `--pd-r-sm`, #5)
  - 26: 모집 공고·시트
  - 22: 목차·상세 사진
  - 16: 게시판 사진·마감 띠·센터 사진
  - 14: 차트 썸네일
  - 6: 표 수 판
  - 4: 폴라로이드
- 간격: 휴대폰 좌우 여백 16, 섹션 사이 약 40이에요.
- 그림자
  - 사진 위 큰 글자에는 아래로 2px 그림자를 둬요. 사진 아래쪽에는 그늘(투명 → `--pd-shade` 55%)을 깔아요.
  - 센터 화보처럼 사진 맨 아래에 이름이 붙는 곳은 그늘을 투명 → 35%(중간) → 72%(끝)로 깔고, 글자에 퍼지는 그림자(0 1px 3px, 60%)를 한 겹 더해요. 흰 사진 위에서도 이름이 읽히게 하려는 것이에요(#4 리뷰).
  - 떠 있는 것(로그인 시트, 댓글 입력줄)에만 그림자를 써요.

## 화면 표기 (#12)
- 게시판 이름은 `BOARD_NAME`(`shared/lib/format.ts`) 한 곳에서 나온다: 댕댕이(`dog`)·냥이(`cat`). 이 문서의 "강아지·고양이"는 게시판 종류를 뜻하는 말이고, 화면에 찍히는 글자는 댕댕이·냥이다.
- 회차 이름(#20): 화면에는 "라운드"·"결선"을 쓰지 않는다. `roundName` 이 주간 → "N주차", 결선 → "마지막 주차"(데뷔 평가)로 준다. 코드·DB·문서의 라운드(round)는 그대로 내부 용어다.

## #5 에서 더한 화면·부품(2026-11-18)
- **입력칸**: 높이 48, 테두리 `--pd-jelly` 1px, 모서리 `--pd-r-sm`, 글자 16px(iOS 확대 막기). 포커스는 `--pd-pink` 3px 윤곽, 오류는 테두리 `--pd-pink` + 아래 `--pd-pink-text` 문구. 글자 수는 이름표 오른쪽에 `4/20`.
- **선택 표시**: 이름표 옆 작은 알약(`--pd-paper-2` 바탕, `--pd-fs-tiny`).
- **사진 칸**: 4:5, 3칸 격자. 빈 칸은 점선 `--pd-jelly` 2px + "사진 고르기". 첫 장에 버터색 "대표" 표, 아래 ← → ✕ 둥근 버튼(사진 위 `--pd-shade` 60%).
- **미리보기 카드**: 게시판 카드와 같은 비율·이름·표 수·"내 글" 얼굴. 데스크톱은 오른쪽 `--pd-paper-2` 판 안에 따라 내려온다(sticky).
