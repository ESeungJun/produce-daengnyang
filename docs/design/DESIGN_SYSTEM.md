- 원본 토큰: [`shared/styles/tokens.css`](../../shared/styles/tokens.css). 이 문서와 값이 1:1로 같아요.
- 견본 페이지(Artifact)와 확정 시안 링크: [FIGMA.md](FIGMA.md)의 "디자인 원본 위치"
- 확정 시안 파일: `.work/mockups/시안_확정_V2A.html`(휴대폰 메인 라이트·다크, 강아지 게시판, 글 상세, 데스크톱 메인)
- Figma는 쓰지 않아요. 사용자 Figma 계정이 보기 권한뿐이라 Artifact 견본 페이지로 대신해요(결정기록 2026-11-17).

## 0. 어떻게 정해졌나
v2(귀여운 매거진)를 처음 그렸어요. 그런데 검수를 건너뛰었고, 사용자가 "AI 티가 난다"고 지적했어요. 그래서 앱 화면 규칙으로 v3(무채색 장부)를 다시 그렸어요.

v3를 비교해 본 사용자의 판단은 이랬어요. **매거진 느낌, 배치, UI 부품은 v2가 낫고 색감은 v3가 낫다.** 그래서 v2를 그대로 두고 색 토큰만 바꾼 A안(v3 색감)과 B안(v2 색 다듬기)을 만들었고, 사용자가 **A안을 확정**했어요(결정기록 2026-11-18).

- 사진 위 글자 그림자·그늘, 알약 칩, 점선 같은 v2 부품은 사용자 결정으로 유지해요. design-taste-frontend의 앱 화면 규칙과는 일부러 다르게 가요.
- v2 원본에서 대비가 모자랐던 곳은 A안에서 고쳤어요.

## 1. 컨셉
매달 한 권 나오는 반려동물 잡지예요. 휴대폰 메인은 한 권을 넘기는 순서로 놓여요.

1. 표지: 그달 데뷔한 아이
2. 목차
3. 화보: 이번 주 센터
4. 차트: 라운드 순위
5. 후보 폴라로이드: 데뷔조 후보
6. 모집 공고: 연습생 등록
7. 맨 아래 제호

틀은 종이·잉크·회색이고, **분홍 하나**가 "누르는 곳"과 강조를 맡아요. 귀여움은 굵은 제호 글꼴, 알약 모양, 얼굴 픽 버튼, 기울어진 폴라로이드가 맡아요.

## 3. 글자
- 제호·제목·숫자는 **Black Han Sans**, 본문은 **Gowun Dodum**이에요(Google Fonts).
- 크기: 표지 제호 58, 표지 이름 52, 맨 아래 제호 44, 게시판 제목 38(글 상세 이름 40), 섹션 제목 32, 순위 숫자 30, 마감 시계·시트 제목 24, 목차 제목 22, 윗줄 로고 20, 본문 15, 보조 13, 표 수·날짜 12.
- 숫자는 `tabular-nums`라 자리 폭이 고정돼요.

## 4. 모서리·간격·그림자
- 모서리
  - 알약 999: 버튼·탭·칩(입력칸은 `--pd-r-sm`, #5)
  - 26: 모집 공고·시트
  - 22: 목차·상세 사진
  - 16: 게시판 사진·마감 띠·센터 사진
  - 14: 차트 썸네일
  - 6: 표 수 판
  - 4: 폴라로이드
- 간격: 휴대폰 좌우 여백 16, 섹션 사이 약 40이에요.
- 그림자
  - 사진 위 큰 글자에는 아래로 2px 그림자를 둬요. 사진 아래쪽에는 그늘(투명 → `--pd-shade` 55%)을 깔아요.
  - 센터 화보처럼 사진 맨 아래에 이름이 붙는 곳은 그늘을 투명 → 35%(중간) → 72%(끝)로 깔고, 글자에 퍼지는 그림자(0 1px 3px, 60%)를 한 겹 더해요. 흰 사진 위에서도 이름이 읽히게 하려는 것이에요(#4 리뷰).
  - 떠 있는 것(로그인 시트, 댓글 입력줄)에만 그림자를 써요.

## #4 구현에서 정한 것(2026-11-18)
- 누르는 칸은 44px 이상: 알약·탭·정렬 링크·시트 보조 버튼에 `min-height: 44px`. 표지 넘김 점은 보이는 크기 8px 그대로 두고 padding 으로 24px.
- 포커스 링은 `--pd-pink` 3px(시안 값).
- 보조 버튼(ghost)은 다크에서 바탕과 구분되게 `jelly-2` 1px 안쪽 테두리.
- 데스크톱(1024px~) 섹션 제목 52px, 설명 16px(시안 `.desk .dsec`).
- 휴대폰 게시판에는 제목 아래 강아지·고양이 탭(링크)을 둔다. 데스크톱은 윗줄 메뉴로 바꾼다.
- 글자 크기는 모두 토큰이다(#11). 보조 크기 `--pd-fs-ui` 14 · `name` 16 · `micro` 11 · `pick-lg` 20 · `card` 26 · `ad` 34 · `name-lg` 40, 데스크톱 전용 `--pd-fs-d-*`(logo 26 · board 28 · card 36 · section 52 · star 84 · cover 120 · close 150). CSS 모듈에 px 글자 크기를 새로 쓰지 않는다.

## #5 에서 더한 화면·부품(2026-11-18)
- **입력칸**: 높이 48, 테두리 `--pd-jelly` 1px, 모서리 `--pd-r-sm`, 글자 16px(iOS 확대 막기). 포커스는 `--pd-pink` 3px 윤곽, 오류는 테두리 `--pd-pink` + 아래 `--pd-pink-text` 문구. 글자 수는 이름표 오른쪽에 `4/20`.
- **선택 표시**: 이름표 옆 작은 알약(`--pd-paper-2` 바탕, `--pd-fs-tiny`).
- **사진 칸**: 4:5, 3칸 격자. 빈 칸은 점선 `--pd-jelly` 2px + "사진 고르기". 첫 장에 버터색 "대표" 표, 아래 ← → ✕ 둥근 버튼(사진 위 `--pd-shade` 60%).
- **미리보기 카드**: 게시판 카드와 같은 비율·이름·표 수·"내 글" 얼굴. 데스크톱은 오른쪽 `--pd-paper-2` 판 안에 따라 내려온다(sticky).
- **상태 알약**(내 글): 투표 중 `--pd-pink`, 순위·역할 `--pd-butter`, 마감·숨김 `--pd-paper-2`.
- **계정 줄**: 로그아웃은 테두리 알약, 회원 탈퇴는 회색 밑줄 글자(+ 확인 시트). 위험한 버튼을 크게 두지 않는다. 구분선은 `--pd-jelly-2`.
- **위험 확인 시트**(`Sheet danger`): 탈퇴·글 지우기. 뒤를 막(`--pd-shade` 40%)으로 덮고, 첫 초점은 "그만둘게요", 주 버튼은 잉크 2px 테두리 알약(분홍은 누르는 곳 전용이라 쓰지 않음).
- **사진 칸 버튼**: 보이는 원 32px, 누르는 칸 44px(`::before`). 갈 수 없는 방향의 화살표는 그리지 않는다.
- **안내 판**(등록 직후 공유 띠·앱 안 브라우저 안내): 바탕 `--pd-ad`, 테두리 `--pd-jelly-2` 1px, 모서리 `--pd-r-md`. 굵은 한 줄 + `--pd-ink-2` 설명 + 오른쪽(휴대폰은 아래) 잉크 알약. 분홍은 쓰지 않는다.
- **입력칸 모서리**는 `--pd-r-sm`(14). 알약 999 는 버튼·탭·칩.
- **윗줄 "내 정보"**: 회원이면 휴대폰·데스크톱 모두 오른쪽 끝. 지금 화면이면 분홍 밑줄. 손님의 "구글로 로그인"은 데스크톱만.
- 화면: `/register`(한 화면 폼 + 미리보기), `/me`(휴대폰 한 줄, 데스크톱 340px 왼쪽 판 + 내 글 목록), `/dog/<글>/edit`(등록 폼 재사용, 픽 받은 글은 사진 잠금).
