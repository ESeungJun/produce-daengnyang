# 동작 기준 v1.0.1

- 릴리스: 2026-11-24 · 이전 기준: v1.0.0
- 이 문서는 이 버전이 어떻게 동작하는지의 기준점이에요. 다음 변경 이슈는 여기 시나리오와 동작을 비교해서(`## 동작 비교`) 다른 게 없으면 닫아요.
- 근거 칸은 릴리스 QA 때 시나리오를 실제로 돌려 채워요(캡처·시험 이름). `수동`은 Claude 가 못 한 것이고 릴리스 QA 보고에 따로 모아요.

## 이번 릴리스에서 바뀐 것

- 기준 바뀜 메인-01: 다름(의도: 예시 데이터를 지워 데뷔 표지 대신 '첫 데뷔를 기다려요'가 나옴) (#33) → 표의 기대 칸에 반영함
- 기준 바뀜 게시판-01: 다름(의도: 글이 없어 센터 카드 대신 빈 안내와 등록 버튼, 주차·마감·찾기·정렬은 같음) (#33) → 표의 기대 칸에 반영함
- 기준 바뀜 명예-01: 다름(의도: 기록이 없어 '아직 전당에 오른 아이가 없어요' 빈 안내) (#33) → 표의 기대 칸에 반영함

- 화면 밖 변경: 탭 아이콘(favicon)·홈 화면 아이콘을 '댕냥' 글자로 다시 만듦(#35). 시나리오는 그대로예요.
- 나머지 시나리오는 #33~#35가 건드리지 않아 v1.0.0 기준과 같아요. 근거 칸이 빈 곳은 v1.0.0 문서의 근거를 따라요.
