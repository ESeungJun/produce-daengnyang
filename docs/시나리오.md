# 시나리오

사용자가 원래 하려던 일을 끝까지 할 수 있는지 보는 흐름 목록이에요(`scenario-review` 1절).
- 단계는 `docs/기능지도.md` 의 기능 ID(F1…)로 써요. 지도의 시나리오 칸에도 같은 SC ID 를 적어요.
- 이 문서가 릴리스 태그(`vX.Y.Z`)에 고정되면 그 버전의 동작 기준이 돼요. 다음 이슈는 태그의 이 문서와 동작을 비교해 닫아요.
- 옛 기준 문서 `docs/동작기준/v1.0.0.md`·`v1.0.1.md` 는 그때 근거(캡처 경로)를 보려고 남겨 둬요. 그 문서의 시나리오 ID 는 "옛 ID" 칸에 이어 적었어요. 새 기준은 이 문서 하나예요(#38, 2026-11-25).
- 확인 칸: `자동` = `scripts/verify/` 스크립트(대부분 Playwright E2E), `브라우저` = 화면을 직접 열어 봄, `수동` = 실제 계정·기기가 있어야 해서 사람이 확인해 주셔야 하는 것.
- 주간 투표가 없는 날(21일, 22일~말일)에는 주간 흐름 E2E 가 건너뛰어져요. 그날 돌린 결과는 ⏸ 로 적어요.
